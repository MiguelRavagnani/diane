# Format

The files will be markdown. For the journal, the files are append only, nad the title is the journal's date. So:

`journal/2026-07-03.md`

```markdown
# 2026-07-13

- 09:12 stantup: Lorem ipsum...
- 10:45 idea: Vai tomano
```

And the archive files will have a formatter header. This should help with Obsidian stuff later:

`kafka-issues`

```markdown
---
title: Kafka Issues
created: 2026-07-18
updated: 2026-07-19
tags: kafka, issues, backend
---

Several stuff broke oops!
```
